# Ra Biker Pet Store

Shopify Online Store 2.0 theme project for dogs and cats.

## Approved design direction
- Cream and pale blue palette, dark modern typography
- Editorial, natural pet photography featuring a dog and cat
- Headline: Better days for dogs & cats.
- Separate Shop Dogs and Shop Cats calls to action
- Spacious layout, rounded category cards, premium responsive storefront

All theme work will be developed on feature/phase-1-storefront. Do not publish or deploy without approval.
